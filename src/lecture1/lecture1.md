## 1. Структура программы

[Объявление пакета и класса](Main.java#L1-L12):

```java
package lecture1;

public class Main {
    // Методы класса.
}
```

`package lecture1` задаёт пакет, поэтому полное имя класса — `lecture1.Main`. В проекте исходник находится в соответствующей папке ``.

[Метод `main`](Main.java#L40) — точка входа при обычном запуске этого класса:

```java
public static void main(String[] args)
```

- `public` — метод доступен извне класса.
- `static` — для вызова не нужен объект `Main`.
- `void` — метод не возвращает значение.
- `String[] args` — массив аргументов командной строки.

## 2. Примитивные типы

В Java восемь примитивных типов. Они хранят простые значения; массивы и строки относятся к ссылочным типам.

### Целые числа

[Объявления переменных](Main.java#L41-L44):

| Тип | Размер | Диапазон |
| --- | --- | --- |
| `byte` | 8 бит | от −128 до 127 |
| `short` | 16 бит | от −32 768 до 32 767 |
| `int` | 32 бита | от −2³¹ до 2³¹ − 1 |
| `long` | 64 бита | от −2⁶³ до 2⁶³ − 1 |

Суффикс `L` в `7L` обозначает литерал типа `long`. Без суффикса обычный целочисленный литерал имеет тип `int`, если его значение допустимо для этого типа.

Знаковые целые представлены в дополнительном коде. Для получения представления отрицательного числа можно инвертировать биты положительного числа и прибавить единицу в пределах разрядности типа. Например, для восьми бит: `6` — `00000110`, а `-6` — `11111010`.

### Переполнение и приведение типов

[Пример умножения](Main.java#L47-L57):

```java
int a = 1000000000;
int b = 1000000000;

System.out.println(a * b);
System.out.println((long) (a * b));
System.out.println((long) a * b);
```

Тип вычисления определяется типами операндов. В первых двух выражениях сначала выполняется умножение двух `int`, и результат переполняется. Обычное целочисленное умножение при переполнении не выбрасывает исключение: сохраняются младшие биты результата.

Приведение уже вычисленного результата к `long` не восстанавливает потерянные биты. В третьем выражении `a` преобразуется **до умножения**, поэтому и `b` участвует в операции как `long`.

Вывод:

```text
-1486618624
-1486618624
1000000000000000000
```

### Деление

В [строке 61](Main.java#L61) выражение `5 / 2` возвращает `2`: оба операнда целые, поэтому дробная часть отбрасывается с округлением к нулю.

Чтобы получить `2.5`, хотя бы один операнд должен быть вещественным: `5.0 / 2` или `(double) 5 / 2`. В [строке 69](Main.java#L69) `(double) intNumber / longNumber` по этой причине даёт вещественный результат `6.0 / 7`.

### `float` и `double`

[Пример объявления](Main.java#L64-L67):

```java
float floatNumber = 2.5f;
double doubleNumber = 2.5;
```

`float` использует 32 бита, `double` — 64 бита. Вещественный литерал без суффикса имеет тип `double`, поэтому для `float` здесь указан суффикс `f`.

Оба типа используют двоичное представление IEEE 754: знак, порядок и значащую часть. У `float` это 1 бит знака, 8 бит порядка и 23 явно хранимых бита дробной части. Для нормальных чисел есть ещё неявная ведущая единица, а порядок хранится со смещением 127: значение имеет вид `(-1)^sign × (1 + fraction) × 2^(exponent - 127)`. Поэтому формула в комментарии исходника упрощена. Для нуля и субнормальных чисел действуют отдельные правила.

Не каждая десятичная дробь представима точно в двоичном виде. Например, `0.1 + 0.2` не обязано совпасть с `0.3`. Также существуют специальные значения `NaN` и положительная и отрицательная бесконечности.

### `char`

[Пример с символами](Main.java#L73-L77):

```java
char charVar = 'C';
char numericCharVar = 123;
```

`char` — беззнаковое 16-битное значение от 0 до 65 535, представляющее одну кодовую единицу UTF-16. Многие символы помещаются в один `char`, но некоторые, например многие эмодзи, занимают пару `char`.

Число `123` соответствует символу `{`. В арифметическом выражении значения `char` преобразуются в `int`, поэтому `'C' - ('A' - 1)` равно `3`.

### `boolean`

В [строке 81](Main.java#L81) переменная `someFlag` получает значение `true`. Второе возможное значение — `false`.

Java не задаёт единый размер хранения `boolean` в памяти для всех случаев. Его нельзя универсально считать ни одним битом, ни одним байтом. Числа автоматически в `boolean` не преобразуются: условие `if (1)` недопустимо.

## 3. Ветвления

### `if` / `else if` / `else`

[Цепочка условий](Main.java#L85-L96) проверяется сверху вниз. Выполняется первая подходящая ветка; оставшиеся пропускаются. Если ни одно условие не истинно, выполняется `else`.

При `weekDay = 2` этот блок выводит:

```text
Tuesday
Вторник
```

`=` присваивает значение, а `==` сравнивает. Для чисел также доступны `!=`, `<`, `>`, `<=`, `>=`. Логические условия можно объединять через `&&` («и») и `||` («или»); `!` означает отрицание.

### Классический `switch`

В [строках 98–111](Main.java#L98-L111) используется форма с `case ...:`. После совпадения выполнение начинается с соответствующей метки и может продолжиться через следующие ветки. `break` завершает `switch` и предотвращает такое продолжение. `default` обрабатывает значения без подходящего `case`.

### Стрелочный `switch`

В [строках 113–121](Main.java#L113-L121) ветки записаны через `->`. Автоматического перехода в следующую ветку здесь нет, поэтому `break` не нужен. Несколько действий одной ветки заключаются в `{ ... }`.

### Выражение `switch`

[Присваивание `message`](Main.java#L123-L130) использует `switch`, который возвращает значение. При `weekDay = 2` это строка `"ВТОРНИК"`. После закрывающей скобки стоит `;`, потому что завершается присваивание.

Такой же приём используется в [методе `getWeekdayLiteral`](Main.java#L14-L21). Если ветка выражения `switch` содержит блок, для выдачи значения из него используется `yield`.

Стрелочные ветки и выражения `switch` доступны без режима preview начиная с Java 14, поэтому для этого исходника нужен JDK 14 или новее.

## 4. Циклы и инкремент

### `while`

[Цикл `while`](Main.java#L133-L137) проверяет условие **перед каждой итерацией**. Пока `weekDay < 7`, выполняется тело цикла.

К этому моменту `weekDay` равен `2`. Выражение `++weekDay` сначала увеличивает переменную и затем возвращает новое значение. Поэтому на итерациях печатаются пары `3 / 3`, `4 / 4`, …, `7 / 7`, а перед каждой парой — `-------`. После цикла `weekDay` равен `7`.

### `for`

[Цикл со счётчиком](Main.java#L139-L141) имеет три части:

```java
for (int i = 0; i < 7; i++) {
    System.out.println(getWeekdayLiteral(i));
}
```

`int i = 0` выполняется один раз. Условие `i < 7` проверяется перед итерацией, а `i++` выполняется после тела. Значения `i` — от `0` до `6` включительно.

Метод распознаёт только `1`, `2` и `3`, поэтому для `0`, `4`, `5` и `6` выводится `Любой другой день`.

### `++x` и `x++`

В обоих случаях переменная увеличивается на единицу. Различается значение самого выражения: `++x` возвращает новое значение, `x++` — старое.

Это видно в [строке 151](Main.java#L150-L152): `array1[i]++` сначала отдаёт старый элемент для вывода, затем увеличивает его. Следующее обращение `array1[i]` в той же строке уже читает новое значение. Например, первая строка вывода — `1 2 0`.

## 5. Методы и рекурсия

[Метод `getWeekdayLiteral`](Main.java#L14-L21) принимает один аргумент `int` и возвращает `String`. `return` возвращает значение и завершает вызов метода. Каждый вызов получает собственные параметры и локальные переменные.

В [методе `fibonacci`](Main.java#L22-L32) используется рекурсия — вызов метода из самого себя:

```java
return fibonacci(number - 1) + fibonacci(number - 2);
```

Базовые случаи `number == 0` и `number == 1` останавливают рекурсию. Для остальных неотрицательных аргументов результат складывается из двух предыдущих чисел. Поэтому [вызов `fibonacci(6)`](Main.java#L144) возвращает `8`.

Эта реализация многократно вычисляет одни и те же значения, поэтому время работы растёт экспоненциально. Для больших аргументов удобнее цикл или сохранение уже вычисленных результатов. Возвращаемый `int` также может переполниться.

Отрицательные аргументы метод не обрабатывает: на практике рекурсия исчерпает стек вызовов и приведёт к `StackOverflowError`.

## 6. Массивы

[Три способа создания](Main.java#L146-L148):

```java
int[] array1 = new int[]{1, 2, 3, 4, 5};
int[] array2 = {1, 2, 3, 4, 5};
int[] array3 = new int[5];
```

Каждая строка создаёт отдельный массив. У первых двух указаны начальные элементы, у третьего все элементы изначально равны `0`. Размер массива после создания не меняется.

Индексы начинаются с нуля. Для массива длины 5 допустимы индексы от 0 до 4. Длина читается через `array.length` без скобок, а выход за границы приводит к `ArrayIndexOutOfBoundsException`.

После [цикла с инкрементом](Main.java#L150-L152) `array1` содержит `{2, 3, 4, 5, 6}`. Затем [цикл for-each](Main.java#L157-L159) последовательно выводит эти значения. Переменная `i` в for-each получает копию очередного значения `int`: присваивание нового числа самой `i` не изменило бы элемент массива.

### Ссылки и передача аргументов

Переменная типа `int[]` хранит ссылку на массив. Присваивание `int[] other = array3` скопировало бы ссылку: обе переменные указывали бы на один объект, и изменение `other[0]` было бы видно через `array3[0]`.

Java передаёт аргументы **по значению**. Для массива копируется значение ссылки, поэтому параметр `arr` в [методе `update`](Main.java#L34-L38) первоначально указывает на тот же массив, что и `array3` у вызывающего кода.

Однако внутри `update` создаётся новый массив `localArr`. Вызов `System.arraycopy(arr, 0, localArr, 0, 5)` копирует пять элементов из исходного массива в новый, после чего меняется только `localArr[0]`.

Поэтому [после `update(array3)`](Main.java#L154-L155) выводится `0`: исходный массив не изменился. Если бы метод выполнял `arr[0] = 5`, изменение было бы видно вызывающему коду.

Метод рассчитан на ссылку, отличную от `null`, и массив длины не меньше пяти. При `null` копирование вызовет `NullPointerException`, а при меньшей длине — исключение о выходе за границы. Для массива объектов аналогичное копирование переносит ссылки на элементы, не создавая копии самих объектов.

## 7. Строки

`String` — ссылочный тип. Строки неизменяемы: после создания содержимое объекта `String` изменить нельзя. Операции со строками дают результирующую строку, не меняя исходные объекты.

[Оператор `+`](Main.java#L161-L164) соединяет строки: `"Bla" + "Blo"` даёт `"BlaBlo"`.

### `==`, `equals` и пул строк

[Пример сравнения](Main.java#L166-L171):

```java
String stringThree = "Bla";
String stringFour = new String("Bla");

System.out.println(stringOne == stringThree);     // true
System.out.println(stringOne == stringFour);      // false
System.out.println(stringOne.equals(stringFour)); // true
```

Для ссылочных типов `==` проверяет, указывают ли ссылки на один объект. Одинаковые строковые литералы `"Bla"` используют объект из пула строк, поэтому первое сравнение даёт `true`. Выражение `new String("Bla")` создаёт отдельный объект, поэтому второе сравнение даёт `false`.

Метод `equals` у `String` сравнивает содержимое, поэтому третье сравнение даёт `true`. Для проверки текста следует использовать `equals`. Если переменная может быть `null`, запись `"Bla".equals(value)` позволяет сравнить её с литералом без `NullPointerException`.

### Доступ к символам

[Метод `charAt`](Main.java#L173-L174) возвращает `char` по индексу с нуля. Для `stringTwo`, содержащей `"Blo"`, `charAt(2)` возвращает `'o'`. В строке `"Bla"` по этому индексу находится `'a'`, поэтому последнее сравнение выводит `false`.

Строковая длина читается через `length()`, а длина массива — через поле `length`. Для строки допустимы индексы от `0` до `length() - 1`; длина и индексы считаются в кодовых единицах UTF-16.
